Préparer son ordinateur

Pour les exercices, nous utiliserons Python dans des notebooks Jupyter. Anaconda Distribution permet d’installer ces outils sur votre ordinateur.

Merci de réaliser l’installation avant le début de l’atelier, si possible, et d’apporter votre ordinateur portable ainsi que son chargeur.

1. Télécharger Anaconda

Rendez-vous sur le site officiel et choisissez Anaconda Distribution, puis le programme d’installation correspondant à votre ordinateur : Windows, macOS ou Linux.

Télécharger Anaconda Distribution

Prévoyez une connexion Internet pour le téléchargement et l’installation.

2. Installer Anaconda

  1. Ouvrez le programme d’installation téléchargé. Sous Linux, suivez les instructions du guide officiel.
  2. Suivez les étapes affichées et conservez les options recommandées par le programme d’installation.
  3. Attendez la fin de l’installation avant de fermer la fenêtre.

Les instructions détaillées pour chaque système sont disponibles dans le guide officiel d’installation .

3. Ouvrir Jupyter Notebook

Si Anaconda Navigator est disponible sur votre ordinateur, ouvrez-le puis lancez Jupyter Notebook. Vous pouvez également démarrer Jupyter avec la méthode suivante :

  1. Sous Windows, ouvrez Anaconda Prompt depuis le menu Démarrer. Sous macOS ou Linux, ouvrez un terminal configuré lors de l’installation d’Anaconda.
  2. Saisissez la commande ci-dessous, puis appuyez sur Entrée. 
jupyter notebook

Jupyter s’ouvre dans votre navigateur. Le notebook s’exécute sur votre ordinateur : une connexion Internet n’est pas nécessaire pour effectuer les exercices locaux une fois les outils installés.

4. Exécuter un premier programme

  1. Dans Jupyter, créez un nouveau notebook et sélectionnez le noyau Python 3.
  2. Copiez le code suivant dans la première cellule.
  3. Appuyez sur Maj + Entrée pour exécuter la cellule. 
print("Bonjour !")
print(2 + 3)

Le résultat attendu est :

Bonjour !

Dans une nouvelle cellule, exécutez le code suivant. Vous apprendrez à utiliser ces bibliothèques pendant l’atelier. 

import numpy
import pandas
import matplotlib
import sklearn

print("Les bibliothèques sont disponibles.")

Si le message s’affiche sans erreur, les bibliothèques nécessaires sont disponibles dans votre notebook.

En cas de difficulté

Si une étape ne fonctionne pas, faites une capture d’écran du message d’erreur et précisez votre système : Windows, macOS ou Linux. Envoyez ces informations à mmmhr@leeds.ac.uk.
