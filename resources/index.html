Mercredi — Python pour les données scientifiques

Introduction aux principaux outils Python utilisés pour manipuler, analyser et visualiser des données : NumPy, pandas et Matplotlib.

Introduction au machine learning supervisé : variables explicatives, variable cible, séparation entraînement/test, entraînement et évaluation de modèles de régression avec scikit-learn.

Vendredi — Classification

Jeux de données et projets de groupe

À partir de mercredi, chaque groupe travaillera progressivement sur un jeu de données afin de mettre en pratique les notions de manipulation de données, de visualisation et de machine learning.

Les jeux de données seront accompagnés d’une description des variables et des objectifs du projet.
